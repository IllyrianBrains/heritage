# Organizo një fushatë

Një kërkesë e mirë thotë **çfarë duhet të ndryshojë, kush mund ta ndryshojë dhe deri kur**.

## Harto palët

| Palë | Pyetja kryesore |
|---|---|
| Komuniteti i prekur | Çfarë përjeton dhe çfarë kërkon? |
| Institucioni përgjegjës | Çfarë kompetence dhe detyrimi ka? |
| Ekspertët | Çfarë mund të verifikojnë? |
| Media dhe publiku | Çfarë duhet të kuptojnë ose bëjnë? |

## Planifiko ritmin

1. Verifiko faktet dhe krijo një bazë të përbashkët burimesh.
2. Kontakto institucionin dhe regjistro përgjigjen.
3. Ndërto aleancën para daljes publike.
4. Cakto treguesit dhe datën e rishikimit.

!!! warning "Siguria dhe pëlqimi"
    Mos publiko emra, fytyra ose vendndodhje të ndjeshme pa pëlqim të informuar.
